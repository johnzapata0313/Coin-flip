# Coin-Flip app

![CBE95635-A904-448D-9714-E9CEABE11A8E](https://github.com/user-attachments/assets/c3df4580-e72b-4db8-95eb-7381fa3f3f15)

This project is a simple and traditional Coin Flip Game Web App built using JavaScript and Node.js. The app features three buttons — one for choosing Heads, one for Tails, and a Flip Coin button to initiate the "coin flip". When you make your selection and click "Flip Coin", the program randomly generates either heads or tails and displays the result directly in the console. We created this web app using basic front-end JavaScript for interactivity and Node.js to handle the backend setup, making it a lightweight and fun project to demonstrate event handling, randomness, and user input in a simple web environment.
